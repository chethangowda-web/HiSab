# BoliHisab v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox syntax.

**Goal:** Remembered rates, multi-day entries, voice commands, voice proof clips, and Wispr Flow
transcription with Chrome fallback.

**Architecture:** Parser and dialogue stay pure and rule-based; new intents (`command`) and draft
fields (`days`, `amountFrom`) flow through the same confirm-before-act state machine. Audio capture is
a browser module; transcription goes through our server proxy. Clips live in their own IndexedDB table.

**Spec:** `docs/superpowers/specs/2026-11-27-v2-voice-design.md` (+ v1 docs in `docs/`).

## Global Constraints

- No keys in the repo or bundle; `WISPR_API_KEY` only in the server environment.
- Nothing saved, deleted or changed without an explicit yes.
- Amounts come from the transcript or the employer's known rate (`amountFrom: 'rate'`), never invented.
- Integer rupees. Multi-day N in 2..31. Every existing test keeps passing.
- Test after each task: `npm test` and `npm run build` green, then commit.

## Review Focus

- "3 din" with no known rate and no amount: asks the amount, never guesses.
- "3 din 2000" (not divisible by 3): asks per-day amount instead of rounding.
- Undo by voice when there are no entries: says so, deletes nothing.
- Wispr returns an unexpected body / 401 / timeout: falls back to Chrome speech, user still sees a result.
- Deleting an entry also deletes its clip; demo-mode clips never mix with real ones.
