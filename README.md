# BoliHisab

A voice-first wage and work tracker for India's informal workers. Speak your workday, wages and advances in Kannada, Hindi or English; BoliHisab keeps the record and tells you what you're owed.

Built for Build for Bharat, Round 2.

## Run

```bash
npm install
npm run dev
```

No API keys are needed. Use Chrome for speech features. See `docs/` for the PRD, TRD, architecture and rules.

## Scripts

- `npm run dev`: start the app
- `npm test`: run unit tests
- `npm run build`: type-check and build
